# Sport24 — Ограничения и дальнейшая работа

## Статус этапа 2

Согласованный состав завершён: утверждён HelveticaNeueCyr, локализованы прежние объекты и документация, добавлены нативные ссылка, вкладки, группа вкладок, закрытый сезон и проверенные метки. Критического препятствия для использования этих компонентов нет. Геометрические отличия при смене шрифта открыто задокументированы; полной пиксельной идентичности браузерному системному шрифту не заявляется.

## Шрифты и метрики

Разрешены только HelveticaNeueCyr и Stag Sans LC. Доступность иных семейств не является требованием или препятствием реализации. Исторические CSS-наблюдения в `/audit/` не определяют активную спецификацию.

- HelveticaNeueCyr доступен во всех 16 найденных начертаниях. Roman и Bold используются по прямой пользовательской спецификации. Это утверждённая типографика дизайн-системы, а не результат обнаружения HelveticaNeueCyr в CSS сайта.
- Stag Sans LC сохранён в прямо подтверждённых ролях. Кнопка не меняла типографику.
- Разные движки формируют естественную ширину и дробные границы текста по-разному. Размеры, интерлиньяж и цвета сохранены; текст не растягивался. У сезона сохранены внешние 82,84375 × 38 и padding, но HUG-текст 52 пкс немного меняет внутреннее центрирование. У бейджа HUG-ширина 70,55 вместо исходной 69,109375; высота 20,375 сохранена. Блочный Auto Layout не полностью воспроизводит CSS inline-метрики и внешние отрицательные margins.

## Непроверенные состояния и роли

- Сезон создан только в закрытом виде. Открытый список, нативный popup ОС, клавиатурное управление и его состояния требуют отдельной проверки.
- Вкладка имеет только активное и неактивное состояния. Дополнительные hover/focus/pressed/disabled варианты не созданы. Переключение варианта в свойствах проверено; интерактивные прототипные переходы не заявляются.
- Настольная группа 856 × 46 отсутствует на сайте при ширине менее 1280. Там используется отдельная нижняя навигация `.HSBqTk`, подписи 12/16,8, контрольная высота 50. Это другой паттерн, он ещё не создан. Мобильный вариант настольной группы не выдумывался.
- Общая ссылка имеет подтверждённое наведение с жёлтым подчёркиванием. Специализированная ссылка матч-центра сохраняет только исходное состояние: её hover ранее не был надёжно измерен.
- Кнопка с иконкой содержит исходное меню; дополнительных состояний нет. Она также выполняет роль контейнера иконки без дублирующего семейства.
- Метка лиги остаётся текстовым примитивом, не полной плашкой с логотипом. Категория «Хоккей» и «Эксклюзив» созданы по измеренным образцам; остальные типы не заявлены завершёнными.
- Не добавлена малая контурная кнопка действия к заголовку: требуется отдельная проверка и расширение существующего семейства с сохранением его ID.
- Прежний селектор `div.CvNE7C`, названный в аудите Search, содержит подарочную/рекламную графику. Поиск по нему не создавался; требуется корректно определить источник поискового контрола.
- Тень всплывающего блока основана на объявленной CSS-переменной, а не наблюдении всех окон и их состояний.
- Хешированные CSS-классы меняются. Для повторной проверки следует использовать URL, роль элемента и структуру DOM, а затем фиксировать актуальный селектор.

## Адаптивность Figma

Проверены четыре рамки 390/768/1440/1920 и применимые свойства, размеры, соединения и варианты. Figma не выполняет CSS media queries. Смена адаптивности заголовка ручная; настольные вкладки не вставлены в мобильные примеры. Проверка HUG/FILL доказывает поведение Figma-контейнеров, но не эквивалентность видимости каждого паттерна сайту на всех ширинах.

Группа вкладок — согласованное исключение составного компонента в этапе 2. Остальные составные паттерны этапа 3 не создавались. Раздел «04 — Паттерны» содержит только проверочные экземпляры, не готовые страницы.

Публикация библиотеки, Code Connect, приложения и кодовые компоненты не выполнялись: эти действия не входят в текущее задание.
